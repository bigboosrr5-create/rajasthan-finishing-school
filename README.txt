RAJASTHAN FINISHING SCHOOL WEBSITE
===================================

FILES
-----
index.html  = main website
style.css   = complete design/responsive styling
script.js   = mobile menu + active navigation
assets/     = put your real images here

IMAGE NAMES
-----------
assets/college.jpg
assets/activity-1.jpg
assets/activity-2.jpg
assets/activity-3.jpg
assets/activity-4.jpg

HOW TO RUN
----------
1. Install VS Code.
2. Open this folder in VS Code.
3. Make sure the above files are inside the same folder.
4. Put your photos in the assets folder with the exact names above.
5. Open index.html in Chrome.
6. For easiest live preview, install the VS Code "Live Server" extension
   and click "Go Live".

IMPORTANT
---------
Replace the demo phone number, email, social links and Google Form link
with the official details before publishing.

The design is responsive for desktop, laptop, tablet and mobile.
